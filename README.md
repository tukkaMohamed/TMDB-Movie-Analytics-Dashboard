# 🎬 TMDB Movie Analytics Dashboard

## Overview

End-to-End Data Analysis Project using the TMDB Movies Dataset.

This project covers:

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Statistical Testing
- PCA (Principal Component Analysis)
- Interactive Streamlit Dashboard

---

## Dataset Features

- Budget
- Revenue
- Vote Average
- Vote Count
- Popularity
- Runtime
- Genres
- Release Year

---

## Data Preprocessing

- Missing Values Handling
- Duplicate Removal
- Outlier Treatment
- Log Transformation
- Feature Scaling
